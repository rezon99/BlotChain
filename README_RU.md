# BlotChain - Визуализация Криптовалютной Ликвидности в Реальном Времени

## 📋 Описание проекта

**BlotChain** — это современное веб-приложение для интерактивной визуализации взаимосвязей криптовалютных активов и потоков ликвидности в реальном времени. Проект поддерживает трехмерные и векторные режимы отображения (2D SVG, 3D WebGL, WebXR VR), использует данные с публичного API **CoinGecko** и **GraphQL / The Graph** для отслеживания топ криптовалютных активов, AMM-пулов и крупнейших бирж.

Приложение визуализирует криптовалютные активы в виде сетевой диаграммы, где:
- 🔵 **Узлы (Nodes)** — криптовалютные активы, AMM-пулы и биржи
- 📊 **Связи (Connections)** — потоки ликвидности между активами
- ✨ **Частицы** — анимированные элементы, показывающие направление и скорость потока

## 🎯 Реализованные возможности

### 1. 🌐 **Мульти-режимная визуализация**
- **2D SVG Canvas (`Dashboard.tsx`):** Высокопроизводительный 2D интерактивный холст с адаптивной силовой сеткой и сохранением пользовательских позиций.
- **3D WebGL Explorer (`Dashboard3D.tsx`):** Полный 3D обзор на Three.js с орбитальной камерой (`OrbitControls`), светящимися сферами узлов, анимированными потоковыми частицами и динамическим отсечением расстояния (LOD).
- **WebXR VR Space Mode (`DashboardVR.tsx`):** Погружение в 360-градусное космическое пространстве на уровне глаз (y=1.6) с плавающими сферами и векторными трубами ликвидности.
- **Decentraland SDK 7 Metaverse Scene (`decentraland-scene/`):** 100% процедурная метаверс-сцена без внешних GLB моделей с платформами-островами, мостами, информационными билбордами и системой частиц ликвидности.

### 2. ⚡ **Данные в реальном времени и отказоустойчивость**
- **CoinGecko REST API:** Автоматическое обновление каждые 30 секунд с поддержкой обработчика превышения лимитов (HTTP 429) и мгновенным переключением на локальный генератор реалистичных симуляций (`dataSimulator.ts`).
- **GraphQL / The Graph Service (`graphApi.ts`):** Интеграция с DeFi-сабграфами (Uniswap V3, Aave V3, Curve) и подсистема Watchlist (WL) с трансформацией GraphQL сущностей в визуальные графы.
- **MEV Shield Threat Simulation (`mevShieldApi.ts`):** Мониторинг MEV-угроз в реальном времени с отображением рисков и функцией чеканки Proof-of-Protection NFT.

### 3. 🎨 **Визуальное кодирование информации**
- **Цветовая кодировка узлов:**
  - 🟢 **Зелёный** — рост стоимости (> +5%)
  - 🔴 **Красный** — падение стоимости (> -5%)
  - 🟡 **Жёлтый** — высокая волатильность (±20%)
  - ⚫ **Серый** — стабильный актив (±5%)

- **Цветовая кодировка связей:**
  - 🔵 **Синий** — входящий поток ликвидности
  - 🟠 **Оранжевый** — исходящий поток ликвидности

### 4. 🎛️ **Интерактивный интерфейс и доступность**
- **Сравнение активов (VS Mode):** Сравнительный анализ показателей двух выбранных монет в `ComparisonPanel.tsx`.
- **Фильтрация по категориям:** Быстрый отбор активов (Top 10, DEX, CEX, Stablecoins, Protocols).
- **Графики и Sparklines:** Детальные модальные графики истории цен с выбором временных интервалов и ARIA атрибутами для клавиатурной навигации (`ChartModal.tsx`).
- **Управление и режим снимка (`?snapshotMode=1`):** Спец-параметр URL для чистой фиксации визуального состояния автоматизированными инструментами.

## 🏗️ Архитектура монорепозитория

```
BlotChain/
├── src/                      # Основное React + Vite приложение
│   ├── components/           # UI компоненты (2D SVG, 3D WebGL, WebXR VR)
│   ├── services/             # API клиенты (CoinGecko, GraphQL, MEV Shield)
│   ├── hooks/                # Реальное время useRealTimeData
│   └── utils/                # Трансформеры данных, физика, визуализаторы
├── automation/               # Изолированный слой автоматизации и ботов
│   ├── shared/               # Общие типы и единая конфигурация контракта
│   ├── contract/             # Hardhat ERC-721 BlotChainSnapshot контракт (Solidity ^0.8.24)
│   └── bot/                  # Playwright оркестратор снимков, Pinata IPFS & Telegram bot
└── decentraland-scene/       # Decentraland SDK 7 (ECS7) процедурная 3D метаверс сцена
```

## 📦 Установка и запуск

### Требования
- **Node.js** v18+
- **pnpm** (рекомендуется) или npm

### Шаги установки

```bash
# Клонировать репозиторий
git clone https://github.com/riznykst/BlotChain.git
cd BlotChain

# Установить зависимости monorepo
pnpm install

# Запустить режим разработки
pnpm run dev

# Сборка продуктивной версии
pnpm run build

# Проверка линтером
pnpm run lint
```
